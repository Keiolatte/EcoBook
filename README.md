# EcoBook

Platform katalog digital jual-beli buku kuliah bekas (preloved) untuk mengurangi jejak karbon.

## Getting Started

```bash
npm install
npm run dev
```

Buka [http://localhost:3000](http://localhost:3000) di browser.

## Tech Stack

- **Framework**: Next.js 14
- **Styling**: Tailwind CSS
- **Font**: Plus Jakarta Sans
- **Icons**: Lucide React
- **Deployment**: Vercel

## Deploy ke Vercel

1. Push repository ke GitHub
2. Hubungkan repository ke [Vercel](https://vercel.com)
3. Klik Deploy

Atau gunakan Vercel CLI:

```bash
npm i -g vercel
vercel
```
